## 🌟 O Projeto

Este não é apenas um portfólio comum. É uma **experiência digital imersiva** projetada para demonstrar habilidades avançadas de desenvolvimento Full-Stack, design de interface e micro-interações.

### 🚀 Destaques Tecnológicos

- **Interactive Puzzle Auth**: Uma entrada criativa que substitui o login tradicional por um quebra-cabeça de arraste (drag-and-drop) integrado com animações 3D.
- **Shatter Transition**: Efeito cinematográfico de "queda de página" ao desbloquear o acesso.
- **Enterprise Landing Page**: Interface baseada em princípios de design "Linear/Vercel", focada em legibilidade e impacto visual.
- **Scroll Reveal System**: Engine de animações sob demanda que revela o conteúdo conforme a navegação do usuário.

---

## 🛠️ Stack Técnica

### **Frontend**
- **Core**: Vanilla HTML5 & CSS3 (Modern Features).
- **Animações**: CSS Keyframes, Clip-path, Perspective 3D.
- **Lógica**: JavaScript ES6+ (Mobile friendly).

### **Backend**
- **Server**: Node.js & Express.
- **Banco de Dados**: MongoDB (Mongoose).
- **Autenticação**: JWT & Cookie-based sessions.

## 🏁 Como Rodar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/philippe0102/Portfolio-pessoal.git
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Configure o `.env`:**
   Crie um arquivo `.env` na raiz com sua `MONGO_URI` e `JWT_SECRET`.

4. **Inicie o servidor:**
   ```bash
   npm start
   ```
